# ⚡ MHP Resume Online

More than just a static CV, <b>MHP Resume Online</b> is a visual narrative of <b>Phuc's</b> professional journey—blending seamless interactivity, real-time data sync, and a clean, modern aesthetic.

---

### 🌟 Highlights

* 👤 **Dynamic Profile:** Professional summary, core competencies, and verified contact channels.
* 💼 **Timeline & Showcase:** In-depth presentation of engineering experience and featured project case studies.
* ⚡ **Real-time Engine:** Instant state updates and reactive data flow backed by Convex.
* 📝 **Content Hub:** Integrated space for technical writing, visual gallery, and live GitHub contribution feeds.
* 🎨 **Crafted UI/UX:** Responsive dark/light theming with fluid micro-interactions powered by Framer Motion.
