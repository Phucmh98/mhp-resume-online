# MHP Resume Online

A personal resume and portfolio website for Phuc, built to showcase profile information, work experience, projects, blog posts, gallery, and GitHub activity.

## Highlights

- Personal profile and contact links
- Work experience
- Featured projects
- GitHub Activity
- Technology stack
- Personal blog and gallery

## Tech Stack

Next.js, React, TypeScript, Tailwind CSS, Convex, Framer Motion, and shadcn/ui.

## Note

This project is designed as a modern, minimal, responsive online CV with light and dark mode support.
